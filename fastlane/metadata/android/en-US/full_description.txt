<p><i>Tiddloid Lite,</i> a lightweight version of Tiddloid, is an app to work with locally stored TiddlyWikis. Once have some ideas, you can immediately write them down and save it in a tiddler, and sync the Wiki to your other devices so that you can access these ideas anywhere.</p><p>See <a href='https://tiddlywiki.com/' target='_blank' rel='nofollow'>tiddlywiki.com</a> for more details of TiddlyWiki.</p><p><br><b>Features:</b></p><ul><li>Create new Wikis with latest template</li><li>Import existing Wikis from file providers, supporting local and cloud.</li><li>TiddlyWiki detection</li><li>Saving TiddlyWikis to the source file by clicking the Save button</li><li>Creating shortcuts to existing wiki on desktop</li></ul>
